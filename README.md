# SkillSwap Frontend

Static HTML/CSS/JavaScript premium lavender-and-white UI.

Open `frontend/` in VS Code and use Live Server on port 5500. Backend must be running at `http://localhost:8080`.

For deployment, edit `js/config.js` and set `window.SKILLSWAP_API_URL` to the hosted backend URL ending in `/api`. See the root README for current features and security limitations.
